### 1.4 Add DTW Alignment Viewer

**Problem**: DTW alignment data is generated by `local_mixing align` but not surfaced in the UI
**Estimate**: 3-5 hours (backend + UI)

**Backend changes needed first**:
- In `identity_factory/experiment_runner.py`, run `local_mixing align` after heatmap generation
- Write `alignment.json` to the experiment output dir
- Extend `ExperimentResults` in `experiment_models.py` to include alignment payload:
  - `alignment_c_star: Optional[float]`
  - `alignment_path: Optional[List[List[int]]]`
  - `alignment_matrix: Optional[Dict[str, Any]]` (ndarray serde format)

**UI implementation**:
- Create `src/components/experiments/AlignmentViewer.tsx`
- Parse `alignment_matrix` (ndarray `{ dim: [rows, cols], data: [...] }`) into 2D
- Render similarity heatmap (`1 - distance`) with the DTW path overlay
- Show summary stats: `c*`, path length, warp ratio (% non-diagonal steps)
- Guardrails:
  - Alignment supports `<= 64` wires; show a message if `wires > 64`
  - Downsample large matrices (same approach as HeatmapViewer)

- Validate counts (warn if > 10 configs)

### 3.3 Backend: Batch Endpoint

```python
@router.post("/start-batch")
async def start_batch_experiments(request: BatchExperimentRequest):
    """Start multiple experiments sequentially"""
```

**Batch request shape**:
```python
class BatchExperimentRequest(BaseModel):
    name: Optional[str]
    configs: List[ExperimentConfig]
```

**Execution model**:
- Sequential runs (one active subprocess) to avoid GPU/CPU contention
- Track a `batch_id` with per-job statuses
- Cancel stops current job and marks remaining as cancelled

## Definition of Done

- Heatmap and alignment panels render for completed runs with valid data

## Risks and Mitigations

- **Large payloads**: Heatmap/alignment matrices can be huge  
  - Mitigation: downsample server-side or client-side; cap size in API responses
- **Alignment limits**: DTW only supports `<= 64` wires  
  - Mitigation: disable alignment UI and show a hint when out of range
- **History consistency**: In-memory jobs reset on server restart  
  - Mitigation: use filesystem-backed summaries for `/history`
